# SymptomLogger

**SymptomLogger** is a RESTful API that allows users to log their symptoms and potential triggers related to autoimmune diseases. The API provides endpoints for creating, retrieving, updating, and deleting symptom logs. Each log includes details such as notes, severity, timestamp and potential triggers.
This is the foundation for the upcoming Autoimmune Disease dashboard which will be used to collect and analyze symptom data. The API is built using ASP.NET Core and includes features such as authentication with JWT, validation, and error handling.
