# SymptomLogger

**SymptomLogger** is a RESTful API that allows users to log their symptoms related to autoimmune diseases and other important information. The API provides endpoints for creating, retrieving, updating, and deleting symptom logs. Each log includes details such as notes, severity, timestamp and potential triggers.
This is the foundation for the upcoming Autoimmune Disease dashboard which will allow users or researchers to visualize and analyze symptom data. The API is built using ASP.NET Core and includes features such as authentication with JWT, validation, and error handling.
