# SymptomLogger

**SymptomLogger** is a RESTful API that allows patients to log their symptoms related to autoimmune diseases. The API provides endpoints for creating, retrieving, updating, and deleting symptom logs. Each log entry includes details such as the symptom description, severity, and timestamp.
This is the foundation for the upcoming Autoimmune Disease analysis and prediction system, which will utilize the logged symptoms to provide insights and predictions about autoimmune diseases.
